# Logos de Empresas Clientes (Airsens)

Esta carpeta contiene los logos vectoriales SVG oficiales de las 4 corporaciones que confían en Airsens:

1. `warner-bros.svg` - Warner Bros (Escudo oficial en dorado y azul).
2. `chilevision.svg` - Chilevisión (Isotipo geométrico oficial).
3. `agrosuper.svg` - Agrosuper (Isotipo agroindustrial).
4. `sopraval.svg` - Sopraval (Isotipo de procesamiento avícola y cámaras frigoríficas).

Puedes añadir o reemplazar archivos en esta carpeta (en formato `.svg` o `.png`) según sea necesario.
