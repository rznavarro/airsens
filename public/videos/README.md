# Carpeta para videos del Hero y la plataforma

Puedes colocar aquí tu archivo de video con cualquiera de los siguientes nombres recomendados:
- `hero-video.mp4`
- `hero.mp4`
- `hero-airsens.mp4`

Al colocarlo en `/public/videos/hero-video.mp4`, quedará accesible inmediatamente en la ruta `/videos/hero-video.mp4`.
